# docs/decisions/

이 디렉토리는 **아키텍처 결정 기록(Architecture Decision Records)** 을 보관합니다.

## 컨벤션

- 파일명: `<YYYY-MM-DD>-<topic>.md`
- 예시: `2026-05-08-worker-failure-policy.md`
- 설계 결정의 근거와 대안을 기록합니다.

## 템플릿

```markdown
# ADR: <Decision Title>

## Date
<YYYY-MM-DD>

## Status
<Proposed | Accepted | Deprecated | Superseded>

## Context
<결정이 필요한 배경>

## Decision
<내린 결정>

## Alternatives Considered
- <대안 1>: <이유>
- <대안 2>: <이유>

## Consequences
- <결과>
```
