# 05. 시작 화면 구현

## 목표

사용자가 배우고 싶은 주제를 입력하고 학습 트리 생성을 시작할 수 있는 첫 화면을 구현한다.

## 관련 명세

- 3. 핵심 사용자 시나리오: 시나리오 1
- 4. 화면 구성: 화면 1
- 10. UI 요구사항
- 14. Phase 1 완료 조건

## UI 필수 요소

- 서비스명: RootMap
- 설명 문구: “배우고 싶은 주제를 입력하면 선수지식 트리를 생성합니다.”
- 주제 입력창
- 예시 주제 버튼
- 생성 버튼

## 예시 주제

- Transformer
- Rust lifetime
- 가상 메모리
- 데이터베이스 인덱스
- 운영체제 스케줄링

## 구현 작업

### 1. 입력 폼 구현

- 텍스트 입력창
- Enter 키로 생성 가능
- 생성 버튼 클릭으로 생성 가능
- 입력값 trim 처리

### 2. 예시 주제 버튼 구현

- 버튼 클릭 시 입력창에 주제를 채운다.
- 바로 생성할지, 입력만 채울지는 UX에 맞게 결정한다.
- Phase 1에서는 입력만 채우는 방식을 기본으로 한다.

### 3. 생성 요청 연결

- `POST /api/trees/generate` 호출
- 로딩 상태 표시
- 중복 제출 방지
- 성공 시 트리 결과 화면으로 이동

### 4. 에러 표시

- 빈 주제 입력
- LLM 생성 실패
- 네트워크 실패

사용자 친화적 메시지 예시:

```text
학습 트리를 생성하지 못했습니다. 잠시 후 다시 시도해 주세요.
```

## 산출물

- 시작 화면 컴포넌트
- 주제 입력 폼
- 예시 주제 버튼
- 생성 API 연동
- 로딩/에러 상태 UI

## 검증 기준

- 사용자가 텍스트 주제를 입력할 수 있다.
- 예시 버튼으로 빠르게 주제를 선택할 수 있다.
- 생성 버튼을 누르면 트리 생성 API가 호출된다.
- 성공 시 결과 화면으로 이동한다.
