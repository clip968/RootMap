# 08. 트리 UI Concept 표시

## 목표

학습 트리 화면에서 개념이 신규인지·이전에 본 적 있는지·상태 요약을 알 수 있게 한다(위키 노출 최소화, 트리 중심 UX 유지).

## 관련 명세

- 16.1 트리 화면 추가 표시
- 11장 `POST /api/trees/generate`의 `reuse_concepts`(클라이언트가 보내는 필드와 UI 위치 확정)

## 구현 작업

### 1. 데이터 연동

- 05 태스크 응답의 `is_reused_concept` 또는 서버 추가 필드 활용.
- 사용자 concept progress 또는 노드 상태를 레이블에 반영한다.
- 시작(또는 생성 직전) 화면에서 `reuse_concepts`를 사용자에게 노출할지(토글)·기본값을 무엇으로 둘지 결정하고, Phase 05와 동일하게 요청에 실어 보낸다.

### 2. 레이블·토큰

- 예: “새 개념”, “이전에 본 개념”, 상태 `known/partial/unknown` 텍스트.
- 접근성: 색만이 아니라 텍스트/아이콘 라벨 병행.

### 3. 다른 트리 사용 힌트

- 간단히 “다른 학습 주제에서도 사용됨” 정도 가능하면 노출(추가 API 호출 필요 시 성능 고려).

## 마무리

- Phase 1 트리 레이아웃·타이포 패턴 유지한다.
