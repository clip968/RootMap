# 09. Concept 상세 패널 및 주제 맥락 UI

## 목표

노드 클릭 시 명세 16.2의 필수 블록을 한 화면(또는 패널)에서 확인할 수 있게 한다.

## 관련 명세

- 16.2 Concept 상세 패널
- 시나리오 3 설명 재사용·보강

## 구현 작업

### 1. 섹션 구성

1. 개념명, 한 줄 설명
2. 현재 트리 주제에서 왜 필요한지(보강 API 또는 규칙 기반 카피)
3. 기존 설명·주제 맞춤 설명
4. 관련 개념·선수지식 목록(edge 요약 또는 링크)
5. 다른 학습 트리에서의 사용처(06 API 재사용)

### 2. 로딩·폴백

- 보강 LLM 호출 실패 시 기존 explanation만 표시.

### 3. 내비게이션

- 관련 Concept 클릭 시 같은 패널에서 교체 또는 최소 라우트 정의.

## 주의

- 최종 사용자용 위키처럼 보이지 않게 트리 맥락 문구를 상단에 둔다.
