# 09. Phase 4 개인화 UI

## 목표

기존 트리·노드 화면에 개인화 상태·추천·복습·리포트 UX를 더해 명세 14장을 구현한다.

## 관련 명세

- `rootmap_phase_4_spec.md` 14장 전절(UI 요구사항)
- 동일 5장 시나리오(트리 압축, 추천 패널 등)

## 구현 작업

### 14.1 개인화 트리 화면

- 노드별 이해 상태·confidence(또는 단순화 표시)
- 추천 노드 강조, 복습 필요 표시
- “이미 아는 선수지식” 접기
- 추천 이유 표시(짧은 bullet)

### 14.2 추천 패널

- 다음 추천 노드, 우선순위, 이유, “학습 시작” / 상태 변경 액션

### 14.3 Concept 상태 패널(노드 상세)

- 상태·confidence 시각화, 마지막 학습일, 퀴즈, 오개념, 복습 필요

### 14.4 학습 리포트 화면

- 학습 시간, 학습한 개념, 강점·약점, 오개념, 다음 추천 행동

### 14.5 복습 화면

- 우선순위, 개념명, 이유, 관련 트리, 복습·퀴즈 진입

## 완료 기준(DoD)

- API 태스크와 연결되어 실제 데이터가 표시된다.
- §18·22와 UI 관련 항목(개인화 트리 조정·알도록 표시)을 충족할 수 있다.
- 검증 명령: `npm run phase4:ui-smoke` (`apps/web`에서 실행)
